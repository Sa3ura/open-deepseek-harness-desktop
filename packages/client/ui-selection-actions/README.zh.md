# @deepseek-ai/dsh-client-ui-selection-actions

[English](README.md) | 中文

为 Web 与 Electron 对话界面提供选中文字快捷操作。使用鼠标主键在对话列或详情列完成划选后，会出现紧凑的横向工具条；右键点击同一段有效选区时，会出现竖向圆角菜单。两种界面均提供“复制”“在新对话询问”和“添加到当前对话”。

本包在 document 边界监听事件，但只接受完整落在显式 `data-selection-actions-scope` 区域内的 Range。输入框、编辑器、按钮、链接、弹窗、菜单、设置 Portal 与侧边栏均不参与。弹层接管交互前会保存不可变的文字与选区矩形；在操作按钮上按下指针不会提前清除浏览器选区。

“在新对话询问”解析当前会话所属工作区，连接其临时空白会话，写入本地化的 Markdown 引用草稿并打开，但不会发送。“添加到当前对话”把 Markdown 引用追加在已有草稿之后；当前输入框不可用、忙碌、被阻止、会话已移除、正在等待 DSH 交互，或可继续子代理的父级不可用时，该操作会直接隐藏。没有工作区时仍保留“复制”。

两种弹层只使用共享语义主题 token，因此会跟随全部浅色和暗色主题。按 Escape、在外部按下指针、取消选区、切换会话、滚动或缩放窗口都会关闭弹层。

## 模型体验

无，因为浏览器端草稿控件会让选中文字保持在模型上下文之外，直到人类发送生成的草稿。

#### KV Cache 影响

无；本包既不组装也不发送 provider 请求。

## 已知限制与暂缓事项

- 暂不处理触摸长按划选；首版面向桌面 Web 与 Electron 界面的鼠标和触控板操作。
- 操作列表固定。第三方操作注册表要等到出现明确的扩展使用方与权限模型后再设计。

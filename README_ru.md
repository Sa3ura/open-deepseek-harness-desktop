Open DeepSeek Harness Desktop — независимо поддерживаемый сообществом настольный дистрибутив [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness). Он объединяет агентную среду на основе плагинов с визуальным рабочим пространством для совместимых API, пользовательских моделей, рабочих каталогов, сессий, плагинов и Skills.

Проект не является официальным продуктом DeepSeek. Он распространяется по [лицензии MIT](LICENSE) и сейчас находится на этапе предварительной версии для разработчиков.

## Основные возможности

- Настройка DeepSeek или совместимого API, базового URL, ссылки на ключ и идентификаторов моделей при первом запуске или в настройках.
- Постоянные сессии, копирование и удаление сообщений, очистка истории и сводка важных этапов выполнения.
- Контролируемая установка поддерживаемых плагинов в один клик, а также Skills, темы и локальные фоны чата.
- Запуск настольной версии из исходников сначала проверен на macOS. Установщики для Windows и Linux ещё требуют упаковки и нативной проверки.

## Запуск из исходного кода

Установите Node.js `^22.19.0 || >=24.0.0` и pnpm `11.7.0`, затем выполните:

```sh
pnpm install
pnpm run build
pnpm run dev:desktop
```

Полное описание функций, архитектуры, безопасности и статуса платформ находится в [README на английском](README.md) или [README на упрощённом китайском](README.zh.md). Также доступны [справочник настольного приложения](apps/desktop/README.md) и [руководство пользователя](docs/user/guide/index.md).

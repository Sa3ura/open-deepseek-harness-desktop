# Open DeepSeek Harness Desktop

[English](README.md) | [简体中文](README.zh.md) | [繁體中文](README_tw.md) | [日本語](README_ja.md) | [한국어](README_ko.md) | [Deutsch](README_de.md) | [Español](README_es.md) | [Français](README_fr.md) | [Italiano](README_it.md) | [Português](README_pt.md) | [Русский](README_ru.md) | [العربية](README_ar.md) | [Bahasa Indonesia](README_id.md) | ไทย | [Tiếng Việt](README_vi.md)

Open DeepSeek Harness Desktop คือชุดเดสก์ท็อปของ [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) ที่ชุมชนดูแลอย่างเป็นอิสระ โดยรวมรันไทม์เอเจนต์แบบปลั๊กอินเข้ากับพื้นที่ทำงานแบบภาพสำหรับจัดการ API ที่เข้ากันได้ โมเดลที่กำหนดเอง เวิร์กสเปซ เซสชัน ปลั๊กอิน และ Skill

โครงการนี้ไม่ใช่ผลิตภัณฑ์อย่างเป็นทางการของ DeepSeek เผยแพร่ภายใต้ [สัญญาอนุญาต MIT](LICENSE) และขณะนี้อยู่ในช่วงตัวอย่างสำหรับนักพัฒนา

## ความสามารถหลัก

- ตั้งค่า DeepSeek หรือ API ที่เข้ากันได้ พร้อม URL หลัก การอ้างอิงคีย์ และรหัสโมเดลจากขั้นตอนเริ่มต้นหรือหน้าการตั้งค่า
- จัดการเซสชันถาวร คัดลอกหรือลบข้อความ ล้างบทสนทนา และดูสรุปขั้นตอนการทำงานสำคัญ
- ติดตั้งปลั๊กอินรีจิสทรีที่รองรับผ่านขั้นตอนคลิกเดียวแบบควบคุม และใช้ Skill ธีม และพื้นหลังแชตในเครื่อง
- การรันเดสก์ท็อปจากซอร์สได้รับการตรวจสอบบน macOS ก่อน ส่วนตัวติดตั้ง Windows และ Linux ยังต้องจัดแพ็กเกจและตรวจสอบบนระบบจริง

## เรียกใช้จากซอร์ส

ติดตั้ง Node.js `^22.19.0 || >=24.0.0` และ pnpm `11.7.0` แล้วเรียกใช้:

```sh
pnpm install
pnpm run build
pnpm run dev:desktop
```

อ่านรายละเอียดความสามารถ สถาปัตยกรรม ความปลอดภัย และสถานะแพลตฟอร์มได้จาก [README ภาษาอังกฤษ](README.md) หรือ [README ภาษาจีนตัวย่อ](README.zh.md) และดู [เอกสารเดสก์ท็อป](apps/desktop/README.md) กับ [คู่มือผู้ใช้](docs/user/guide/index.md) เพิ่มเติม
